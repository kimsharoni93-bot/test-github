# ניתוח נתוני כדורגל

סקריפט Python שמקבל רשימת משחקים ומחשב סטטיסטיקות שערים: ממוצע, חציון, והשחקן עם מספר השערים הגבוה ביותר.

## דרישות

- Python 3
- ספריית `statistics` (כלולה ב-Python)

## הרצה

```bash
python test.py
```

הדוגמה בקבצים מדפיסה ניתוח על ארבעה משחקים לדוגמה.

## שימוש

הפונקציה `נתח_נתוני_כדורגל` מקבלת רשימה של מילונים. כל מילון מייצג משחק:

| מפתח | סוג | תיאור |
|------|-----|--------|
| `שם שחקן` | `str` | שם השחקן |
| `שערים` | `int` | מספר השערים במשחק |

החזרה:

- `ממוצע שערים למשחק` — ממוצע השערים בכל המשחקים
- `מדד חציוני לשערים` — החציון
- `הכובש הרב ביותר` — השחקן עם סך השערים הגבוה ביותר (שערים נספרים על פני כל המשחקים)

אם הרשימה ריקה, הפונקציה מחזירה `None`.

```python
from test import נתח_נתוני_כדורגל

נתונים = [
    {"שם שחקן": "רון", "שערים": 2},
    {"שם שחקן": "יוסי", "שערים": 1},
    {"שם שחקן": "רון", "שערים": 3},
    {"שם שחקן": "דוד", "שערים": 1},
]

print(נתח_נתוני_כדורגל(נתונים))
```
